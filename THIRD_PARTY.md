# Third-party code

Conductor itself is AGPL-3.0 (see [LICENSE](LICENSE)). These libraries ship inside the app, in `docs/lib/` (and inlined into `docs/conductor.html`):

| File | What it is | License | Source |
|------|-----------|---------|--------|
| `robot-voice.js` | The built-in robot voice: meSpeak 1.9.6 (npm `mespeak` 2.0.2) by Norbert Landsteiner, based on speak.js by Alon Zakai, an Emscripten port of eSpeak by Jonathan Duddington, with its US-English voice. Stored gzipped and base64-encoded; generated by `scripts/build-robot-voice.js`, which removes one `unload` listener and changes nothing else. | GNU GPL v3 or later | [npm mespeak@2.0.2](https://www.npmjs.com/package/mespeak) · [github.com/mikolalysenko/mespeak](https://github.com/mikolalysenko/mespeak) · [masswerk.at/mespeak](https://www.masswerk.at/mespeak/) · [speak.js](https://github.com/kripken/speak.js) · [eSpeak](https://espeak.sourceforge.net/) |
| `pako.min.js` | pako 2.1.0 — gzip in JavaScript | MIT and Zlib | [github.com/nodeca/pako](https://github.com/nodeca/pako) |
| `lame.min.js` | lamejs — MP3 encoder (LAME port) | LGPL-3.0 | [github.com/zhuker/lamejs](https://github.com/zhuker/lamejs) |
| `qr-creator.min.js` | QR Creator (from jquery-qrcode 0.14.0) | MIT | [github.com/nimiq/qr-creator](https://github.com/nimiq/qr-creator) |
| `qr-scanner.legacy.min.js` | QR Scanner | MIT | [github.com/nimiq/qr-scanner](https://github.com/nimiq/qr-scanner) |

To rebuild the robot voice: `npm install`, then `node scripts/build-robot-voice.js` (`--check` reports whether the committed file is current).
